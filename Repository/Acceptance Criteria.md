# **Acceptance Criteria**

| Category | 
|---|
| User Acceptance Criteria | 
| Specialist Acceptance Criteria | 
| Admin Acceptance Criteria |


--------------------
 **1. User Acceptance Criteria**
- کاربر بتواند در سایت ثبت‌نام کند و وارد حساب کاربری خود شود.
- کاربر بتواند پروفایل افراد متخصص رو مشاهده کند.
- کاربر باید بتواند متخصصان را بر اساس مهارت و حوزه تخصصی جست‌وجو کند.
- کاربر باید بتواند درخواست دریافت خدمات تخصصی یا همکاری در پروژه را ثبت کند.
- کاربر بتواند درخواست ثبت‌شده را در صورت نیاز لغو کند.
- کاربر بتواند برای مشکلات یا تخلفات احتمالی، گزارش ثبت کند.
- کاربر باید بتواند درخواست‌های همکاری ثبت‌شده خود را مشاهده کند.
- کاربر بتواند امتیازها و نظرات سایر کاربران درباره متخصصان را مشاهده کند.
- کاربر باید بتواند رمز عبور خود را در صورت فراموشی بازیابی کند.
- کاربر بتواند جزئیات خدمات ارائه‌شده را مشاهده کند.


 **2. Specialist Acceptance Criteria**
 - متخصص بتواند پروفایل تخصصی خود را ایجاد و تکمیل کند.
 - متخصص باید بتواند مهارت‌ها و حوزه‌های تخصصی خود را ثبت کند.
 - متخصص باید بتواند مدارک یا گواهی‌های معتبر مرتبط با تخصص خود را ارائه دهد.
 - متخصص بتواند درخواست‌های همکاری دریافت‌شده را مشاهده کند.
 - متخصص باید بتواند نمونه‌کارهای مرتبط با تخصص خود را نمایش دهد.
 - متخصص بتواند سوابق کاری و تجربه‌های حرفه‌ای خود را به پروفایل اضافه کند.
 - متخصص باید بتواند محدوده جغرافیایی ارائه خدمات خود را مشخص کند.
 - متخصص باید بتواند اطلاعات مربوط به هزینه خدمات خود را ثبت کند.
 - متخصص باید بتواند زمان‌های آزاد خود را برای همکاری مشخص کند.
 - متخصص بتواند اطلاعات تماس خود را مدیریت کند.


**3. Admin Acceptance Criteria**
- مدیر بتواند فهرست کاربران ثبت‌نام‌شده را مشاهده و مدیریت کند.
- مدیر باید بتواند حساب‌های کاربری متخلف را مسدود یا غیرفعال کند.
- مدیر باید بتواند گزارش‌های ارسال‌شده درباره کاربران یا متخصصان را بررسی کند.
- مدیر بتواند دسته‌بندی‌های تخصصی موجود در سایت را ایجاد، ویرایش یا حذف کند.
- مدیر بتواند محتوای نامناسب یا خلاف قوانین سایت را حذف کند.
- مدیر باید بتواند آمار کاربران، متخصصان و درخواست‌های ثبت‌شده را مشاهده کند.
- مدیر بتواند سطح دسترسی کاربران و مدیران دیگر را مدیریت کند.
- مدیر باید بتواند پل ارتباطی لازم بین کاربر و فرد متخصص را برقرار کند.
- مدیر باید بتواند امنبت داده ها و اطلاعات ثبت شده در سایت یا اپلیکیشن را تامین کند.
- مدیر باید بتواند درخواست‌های ثبت‌نام متخصصان را برای تأیید یا رد بررسی کند.
- مدیر باید بتواند مشکلات فنی گزارش‌شده توسط کاربران را پیگیری کند.
