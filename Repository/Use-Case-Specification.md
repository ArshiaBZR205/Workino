# Use Case Specification — Workino

## UC-01: مشاهده و جست‌وجوی متخصصان

| بخش | توضیح |
|------|-------|
| **Actor** | مشتری |
| **Precondition** | — |
| **Main Flow** | ۱. مشتری وارد صفحه متخصصان می‌شود.<br>۲. سیستم فهرست متخصصان را دریافت می‌کند.<br>۳. سیستم فهرست متخصصان را نمایش می‌دهد.<br>۴. مشتری می‌تواند متخصصان را بر اساس تخصص یا موقعیت مکانی جست‌وجو کند. |
| **Alternative** | اگر متخصصی پیدا نشود، سیستم پیام مناسبی نمایش می‌دهد. |
| **Postcondition** | فهرست متخصصان یا نتایج جست‌وجو نمایش داده می‌شود. |

## UC-02: ثبت درخواست خدمات

| بخش | توضیح |
|------|-------|
| **Actor** | مشتری |
| **Precondition** | مشتری وارد حساب کاربری خود شده باشد. |
| **Main Flow** | ۱. مشتری وارد بخش ثبت درخواست می‌شود.<br>۲. اطلاعات و توضیحات خدمات موردنیاز را وارد می‌کند.<br>۳. سیستم اطلاعات را اعتبارسنجی می‌کند.<br>۴. درخواست در سیستم ثبت می‌شود.<br>۵. سیستم پیام ثبت موفق درخواست را نمایش می‌دهد. |
| **Alternative** | اگر اطلاعات ناقص یا نامعتبر باشد، سیستم پیام خطا نمایش می‌دهد. |
| **Postcondition** | درخواست خدمات با موفقیت ثبت می‌شود. |

## UC-03: ثبت‌نام متخصص

| بخش | توضیح |
|------|-------|
| **Actor** | متخصص |
| **Precondition** | متخصص حساب کاربری متخصص نداشته باشد. |
| **Main Flow** | ۱. متخصص وارد صفحه ثبت‌نام می‌شود.<br>۲. اطلاعات موردنیاز را وارد می‌کند.<br>۳. تخصص و مهارت‌های خود را مشخص می‌کند.<br>۴. سیستم اطلاعات را اعتبارسنجی می‌کند.<br>۵. حساب متخصص ایجاد می‌شود. |
| **Alternative** | اگر اطلاعات ناقص یا نامعتبر باشد، سیستم پیام خطا نمایش می‌دهد. |
| **Postcondition** | حساب متخصص ایجاد می‌شود. |

## UC-04: مدیریت متخصصان

| بخش | توضیح |
|------|-------|
| **Actor** | مدیر سایت |
| **Precondition** | مدیر وارد حساب مدیریتی خود شده باشد. |
| **Main Flow** | ۱. مدیر وارد بخش مدیریت متخصصان می‌شود.<br>۲. سیستم فهرست متخصصان را نمایش می‌دهد.<br>۳. مدیر اطلاعات متخصصان را بررسی می‌کند.<br>۴. مدیر در صورت نیاز وضعیت حساب متخصص را تغییر می‌دهد. |
| **Alternative** | اگر متخصصی ثبت‌نام نکرده باشد، سیستم پیام مناسبی نمایش می‌دهد. |
| **Postcondition** | اطلاعات و وضعیت متخصصان مدیریت می‌شود. |
