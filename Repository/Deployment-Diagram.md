# Deployment Diagram — Workino

## 1. مقدمه

این نمودار نحوهٔ ارتباط کاربران با سیستم ورکینو و اجزای اصلی آن را نشان می‌دهد.

## 2. اجزای سیستم

- **User:** کاربرانی که از سیستم استفاده می‌کنند.
- **Web Browser:** مرورگری که کاربران از طریق آن وارد سایت می‌شوند.
- **Application Server:** سروری که درخواست‌های کاربران را پردازش می‌کند.
- **Database:** پایگاه داده‌ای که اطلاعات کاربران، متخصصان و درخواست‌ها را ذخیره می‌کند.
